Static (static positioning)

This is the default value that does not require explicit definition, as elements are automatically positioned in the normal document flow.

Relative (relative positioning)

The element is shifted relative to its original position in the normal flow of the document without affecting the placement of other elements.

Absolute (absolute positioning)

The element is removed from the normal document flow and positioned relative to its nearest positioned ancestor (not static).

Fixed (fixed positioning)

The element is fixed in one place in the browser window and does not move when scrolling the page.

Sticky (sticky positioning)

The element is relatively positioned until it reaches a certain threshold in the form of page scrolling, after which it behaves as fixed.
